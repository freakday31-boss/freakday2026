# Freak Day — publication

Ce dossier contient le site complet. Pour le publier, envoyez **tout son
contenu** à la racine du dépôt GitHub, sans ajouter un dossier parent.

Dans **Settings → Pages**, choisissez la branche `main` et le dossier
`/(root)`. Gardez les noms et dossiers tels quels : les chemins des médias
sont déjà configurés dans le site.

`index.html` est la page d'accueil. Après l'envoi, attendez la fin du
déploiement GitHub Pages avant de tester le site.
